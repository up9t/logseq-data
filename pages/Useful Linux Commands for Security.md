- ## ss (Modern Netstat Replacement)
- `ss` command is used to see what is listening on specific ports. For example
- ```bash
  ss -tulnp
  ```
- - t = list for tcp
- - u = list for udp
- - l = that are currently listening
- - n = show port number instead of the name occupied those ports. e.g port 80 means http
- - p = show process id (needs sudo)
