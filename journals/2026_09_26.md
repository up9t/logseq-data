- If you use Linux for Desktop, there is a command that you must install: `nvtop`. It's a tool to monitor GPU usage on your machine. And no, it's not only for Nvidia GPU, don't let the name fools you, it actually an abbreviation for "Neat Video card Top", so it works if you want to monitor your AMD integrated GPU usage, Intel integrated GPU, and of course discrete GPU like Nvidia.
