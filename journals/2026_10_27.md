- For the past 4 days, I have been trying to learn more about Go programming language, I was trying to update my old project called `khinsider-scraper` which then I renamed it to `khinsider-download`. The project is about scraping a music website, then download the musics from the given url. The website is `downloads.khinsider.com` that's why I named it `khinsider-download`. The website maybe allows the user to download the entire playlist at once, but it requires login first, and actually they don't use JSON api for the data, it's like the server directly render the html to the browser. This app was previously I made using Nodejs, it's a long time ago, and yeah when I see the code I've written long time ago, I don't understand what I was writing. That's why I decided to port it to Go from ground up, and there is actually so much I learn from this simple project. At the end, I was able to make it run very fast, I never see a program I wrote run this fast before, thanks to Go's goroutine which makes me very happy with the result.
