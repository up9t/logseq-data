- To change default terminal editor and visual editor in linux, you can set variables `EDITOR` and `VISUAL` to the path of your desired editor. For example.
- ```bash
  export EDITOR=/usr/bin/vimx
  export VISUAL=/usr/bin/code
  ```
- You might want to manually added those line of codes to the `.bashrc` file in you home directory.
-
- In Modern Linux, `vi` editor usually pointing to `vim` which stands for `vi improved`, basically `vi` plus some features. In Fedora, it comes with package `vim-minimal` from `dnf`. Note that this package has some limitation, for example, if you want to have a copy to system clipboard mechanism you will need another package, such as `wl-clipboard` if you use `wayland` and  package named `vim-X11` will add a different binary called `vimx`, that's the program you want to use instead of `vi` or `vim`.
-
- ```bash
  sudo dnf install -y wl-clipboard vim vim-X11
  ```
