- Let's say you made a change in the app you develop for Android using Kotlin, the way to change the version number is to go to `build.gradle.kts` and look for the android directive and defaultConfig, in there you would see  `versionCode` and `versionName`, when you do update your app, you need to change these two, first, the `versionCode`, it's an integer value, you increment the number by one, this is being used for Play Store to track which version of the app is the later, higher mean the later. And `versionCode` is the code that is being shown to the user, it's a string, but typically you would want to use semantic version convention which formatted like `major.minor.patch` e.g `2.1.43` or `1.1.3`, etc
