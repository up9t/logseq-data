- In computer, there is a hardware component called NVRAM, it's a writable storage for storing UEFI boot entries, something like that. UEFI is a program, we called it `firmware`. When a computer boots, it'll start a UEFI program and look to the NVRAM storage, usually it has multiple entries in there, which you can change the order, but the first order is the one to boot.
- The entry is pointing to partitions in a disk especially the EFI System Partition (ESP) that is using the EFI Filesystem, that's because UEFI can **only** read EFI System Partition though in rare cases it can also read other filesystems too.
- In the EFI Filesystem it'll look for a `.efi` file that has been specified in the NVRAM entry. The `.efi` file is just a C code that has been compiled down to a specific binary format. Now, after executing it, it'll load the kernel, well not that fast, in linux usually there is another program called bootloader named `GRUB` which gets called and runs. A bootloader can and will read multiple filesystems. It has its own entries, so you can choose what Operating System you want to use, the entries is usually stored in another partition, the partition is where we mount to the `/boot` directory in linux.
