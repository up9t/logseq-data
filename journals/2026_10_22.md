## Installing a Nodejs binary through Node Package Manager (NPM)
-
- To install a binary using Nodejs, you can use `npm` with `-g` flag:
-
- ```bash
  npm install -g @opencode/cli
  ```
-
- Depending on your setup, there is a chance that you get a permission denied error when you do that. In my case, because I installed Nodejs through NodeSource repository and with system package manager like `dnf`, I got permission denied as it tried to run the command because it'll try to download and install that binary to the `/usr/local` directory which needs root access.
- To solve this problem, you can use `sudo`, which is not the recommended way, but I'm in a container so not a problem for me. The recommended way which I want to show you instead is by making `npm` to install in a user-specified directory, like `~/.local`, or any custom directory where you like to put all of the binaries you want to install.
-
- ```bash
  npm config set prefix <directory>
  ```
-
- An example, I want to use the `~/.local` directory.
-
- ```bash
  npm config set prefix ~/.local
  
  # Then continue installing the binary
  npm install -g <xxxx>
  ```
-
- This will put the binary inside the `~/.local/bin` directory. If you want to put them elsewhere you just need to remember to set the `prefix` to the desired location, and don't forget to make sure you have set the `PATH` variable to use that location.
-
- ```bash
  npm config set prefix ~/.npm-global
  
  # After doing that, you may want to set a PATH variable.
  # Otherwise you can't directly execute the installed binary.
  export PATH=$PATH:~/.npm-global/bin
  ```
