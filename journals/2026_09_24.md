- In Computer Graphics there are Vertex Shader and Fragment Shader, they both are a code that is executed on GPU instead of CPU.
- A vertex shader code will be executed for every vertex, so a triangle will get executed 3 times.
- A fragment shader code will be executed for every pixel filling that triangle, which is more than 3, actually probably hundred of thousands. It is a very expensive operation, that's why having more code in the vertex shader is better.
