- When you installed Fedora Minimal through Fedora Everything ISO, you might realize after you install a terminal emulator, your shell doesn't show color for your name and hostname. The problem is that you have a missing thing that you need to install, to fix this, all you need to do is to  install `bash-color-prompt` and restart your terminal emulator.
-
- ```bash
  sudo dnf install -y bash-color-prompt
  
  # Restart shell
  exec bash
  ```

- If you install something using `go install <name>`, it will be put in the `$(go env GOPATH)/bin` directory, usually in the `~/home/go/bin`. Now, because we have install command, we expect it to also has uninstall command right? well in this case, no, it doesn't have uninstall command, if you want to uninstall something you have installed, you have to manually delete the binary inside that path.
