## Few things that I discover when learning Go
-
- If you want to trim a string, there are methods you can use through strings library: `strings.TrimRight`, `strings.TrimLeft`, `strings.TrimSuffix`, etc, you got it. The differences between `strings.TrimRight` and `strings.TrimSuffix` is `TrimSuffix` will remove the pattern from the given string once, while `TrimRight` will do it repeatedly until there is no more pattern like that left in the right side of the given string, my takeaway is to use `TrimSuffix` by **default** first. See this example:
- ```go
  strings.TrimRight("hello", "lo")  // he
  strings.TrimRight("helloooo", "lo") // he (hmm!?)
  
  strings.TrimSuffix("hello", "lo") // hel (easier to predict)
  ```
-
- You can convert struct type in Go to JSON string by using `json.Marshal` and `json.Unmarshal`, and if you want to customize the name of the field in the JSON result, you can put the json metadata on the right of your struct's field, like this:
-
- ```go
  type User struct {
      ID     int    `json:"id"`
      Name   string `json:"name"`
      Bio    string `json:"bio,omitempty"` // Omitted if empty string ""
      Secret string `json:"-"`             // Always ignored
  }
  ```

- If you're building a program while utilizing go's goroutines, there is chance you might get lost and confused about what you're doing wrong, the program just running indefinitely, you don't know which goroutine still running a task, go debugger might not enough, thankfully there is an easy way to debug this in Go, that is using `pprof`, use the http pprof, there are also many things you can see in the pprof html server page.

- If you want to check if the key exists in a map, you can do this:
- ```go
  value, exists := myMap[key]
  
  if !exists {
    // key doesn't exists, don't ever use the value
  }
  ```

- You can convert Go's iter.Seq to a slice by using `slices.Collect`.
-
- ```go
  slices.Collect(myIter)
  ```

- If you want to add flag options in your Go cli program, you can use `flag` package. And did you know when you use `-h` when you execute your program, the flag will report all the available flag you define in your program. And did you know when you run the `-h` flag, your main program will get executed until the line `flag.Parse`, which is the required method to parse the defined flags, and the code below it will not get executed.

- Building iteration in Go is very simple, you use the `iter.Seq` signature.
-
- ```go
  type (
  	Seq[V any]     func(yield func(V) bool)
  	Seq2[K, V any] func(yield func(K, V) bool)
  )
  ```
-
- Here's an example of implementing `iter.Seq` and consume them in for loop.
-
- ```go
  func myIteration(yield func(string) bool) {
    for {
      // yield here is to return the value, you can also add if condition
      yield("Hello world")
      
      // example if
      // if condition {
      //   yield(3)
      // }
    }
  }
  
  func main() {
    for value := range myIteration {
      fmt.Println(value) // Hello world (printed infinitely)
    }
  }
  ```
-
- And if you want to add the index, you use the `iter.Seq2`.
-
- ```go
  func myIteration(yield func(int, string) bool) {
    i := 0
    for {
      yield(i, "Hello world")
      i++
    }
  }
  
  func main() {
    for index, value := range myIteration {
      fmt.Println(index,, value) 
      // 1 Hello world
      // 2 Hello world
      // ...
    }
  }
  ```
-
- And a good practice is to check for the return value of the yield function, which indicates the loop has been stopped.
-
- ```go
  if !yield(value) {
    return
  }
  ```
-
- You can also wrap the `iter.Seq` inside a function so you can do it like this:
-
- ```go
  for value := range GetData(4) { // GetData is a function that returns iter.Seq
  }
  
  
  func GetData(i int) iter.Seq[int] {
    return func(yield func(int)bool) {
      yield(i)
    }
  }
  ```
