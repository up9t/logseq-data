- in c/c++ development you need a compiler to compile your projects, there are two compilers that are popular in linux, first is `gcc`, gcc is usually preinstalled by default on most linux system. The other one is called `clang`, clang is actually the frontend, it is based on `llvm` backend.
- `clang` is better in architecture, it uses modular approach while `gcc` uses monolith. For C/C++ development I'll definitely choose `clang`.
- To install clang you can use `dnf` or `apt`, here's how you can install it in fedora.
- ```bash
  sudo dnf install -y clang
  ```
- After done, you will have two main binaries that you can use: `clang` and `clang++`, use `clang` for C development, and `clang++` for C++.
- You might also want to download their linker too called `lld` part of `llvm` project, if you don't use it, it'll use the default GNU `ld`. `ldd` is better as it is multithreaded, `ld` is single-threaded. Using `ldd` would likely to improve linker time 3-5 times faster. Actually there is an even faster linker than `ldd` called `mold`.
- There are also tools that are going to help you easier developing projects. Like `lldb` for debugger, `cmake` for generating build system, `ninja` for the actual build system, `clang-tidy` for linter, `clang-format` for formatter.
- For debugging, `lldb` is a debugger part of llvm project, you actually can just use the `gdb` for debugging Clang-compiled program as long as the program has debug symbols (usually with `-g` flag in the `clang++` or with `CMAKE_BUILD_TYPE=DEBUG` in `cmake`)
- `CMake` has awful syntaxes but it is the industry standard and used in many big projects. There are nicer alternatives for it, such as `meson` but it has less community.
