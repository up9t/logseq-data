- Did you know in Typescript you can have `this` in a class method's first parameter? and you can execute them without specifying any parameters?
-
- ```typescript
  class ABC {
    public myMethod(this: ABC) {} // this worked
    
    
    public execute() {
      this.myMethod(); // worked
    }
  }
  ```
-
- Did you know you can declare a `function` signature as an `interface` in Typescript?
-
- ```typescript
  interface AAA {
    (message: string): void;
  }
  
  function MyFunc(message: string) {} // uses the AAA interface, param name doesn't matter
  
  function Execute(callback: AAA) {}
  
  Execute(MyFunc);
  
  // or
  
  Execute((msg: string) => {
    
  });
  ```
