- In C++, `int a;` will result in undefined behavior, it doesn't use zero value. If you want to use zero value, then use `int a {};`, this will automatically make `a` to have value of zero.
- In C++, consider to use `std::array` instead of C-Style array `int arr[]`. C-Style array is a pointer to that array, while `std::array` is container, it keeps the size of the array by calling `.size()` and you can convert them to C-Style array whenever you want with `.data()`
- In C++, `std::endl` always flush the data which is slow, consider to use `\n` instead.
