- If you need to know if the permission is successful or not in Android development, you can use `registerForActivityResult` API and the parameter of `StartActivityForResult()`, inside the block is where you want to perform check if the intent was successfull or not. Here's an example
- ```Kotlin
  var hasPermission = false
  val packageName = "com.example.example"
  
  fun checkPermission(): Boolean {
    return Settings.canDrawOverlays(this)
  }
  
  // here
  val startForResult = registerForActivityResult(StartActivityForResult()) {
    hasPermission = checkPermission()
  }
  
  val intent = Intent(Settings.ACTION_MANAGE_OVERLAY_PERMISSION, "package:$packageName".toUri())
  
  startForResult.launch(intent)
  ```
