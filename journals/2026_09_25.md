- In Go, there is `array` and `slice` to store multiple array of data as a single variable.
- `Array` has a fixed length that can't be changed.
- `Slice` is a wrapper or a pointer that points to a specific section of an `Array`. It could be pointing to the whole `array`, or just the partial size, for example from A to B instead of from A to Z.
-
- `Slice` has a `capacity` and a `length`. A `capacity` is the fixed length of the underlying array, while `length` is how much the `data` is currently sitting on the specific portion of an array.
- ```go
  // this will create an underlying array with length = 4 filled with 0
  arr := make([]int, 4) // [0, 0, 0, 0]
  
  arr = append(arr, 3, 4) // now the array is [0, 0, 0, 0, 3, 4]
  ```
- If you specified the `length` and the `capacity`, it'll append to the from the first length instead
- ```go
  // slice length = 0 -> currently hold 0 data
  // slice capacity = 4 -> array length = 4
  arr := make([]int, 0, 4) // [0, 0, 0, 0]
  
  arr = append(arr, 1, 3) // [1, 3, 0, 0]
  ```
-
- If you add an element to a `slice` and the underlying `array` has reached its length, then the `Slice` would reallocate that array, it would mean allocate a new space in a memory with a new size, and copy all the data to that new location, then delete the old array. Which is an expensive operation if you ask me.
-
- And if you wonder why `arr = append(arr, 3, 4)` doesn't reallocate a new array each time because the syntax looks like it does is because slice is just wrapper and the underlying array is still there, that's why using `arr = append(arr, ...)` works because it only changes the wrapper. But there is a time where it'll cause reallocation when you try to append data into an array that has reached its maximum capacity.
-
- And here's how you can create `array` instead of `slice`.
- ```go
  // Declares an array of exactly 5 integers initialized to [0, 0, 0, 0, 0]
  var arr1 [5]int 
  
  arr2 := [3]string{"Go", "Python", "Java"} 
  
  // using ... means the compiler will automatically set the size for you
  // based on how much element it consists
  arr3 := [...]int{10, 20, 30, 40} // length = 4
  ```
