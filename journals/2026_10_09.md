- In Javascript, if you want to access global variable especially in the browser, you usually use the `window` object. But `window` object doesn't exists in other environment such as Node.js or Worker. Thankfully there is a universal object that is defined in the Javascript specification called `globalThis`, if you use `globalThis` in the browser it would automatically referring to `window`. So consider to always use `globalThis`. It worked on the other environment too referring to the global object.
