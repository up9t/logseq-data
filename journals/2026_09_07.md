- In Vue.js the difference between `ref` and `reactive` is quite tricky, but I will tell you that you should always use `ref`, and just forget about `reactive`.
- `ref` works for all data type while `reactive` only works for object.
- `ref` needs to use `.value`, while `reactive` doesn't. This reminds me of Kotlin, it can just use the keyword `by` to automatically wrap it with getter and setter.

- `watch` is like `useEffect` in `React`, it works by first specify the dependencies/sources, then the callback.
-
- ```typescript
  watch(x, (newX) => {
    console.log('x is changed');
  });
  
  // if you have multiple sources
  watch([x, y], ([newX, newY], [oldX, oldY]) => {
   
  });
  
  // you can also use like computed getter
  watch(() => x.value + y.value, (sum) => {
  
  });
  ```
-
- All of the calls above trigger the function whenever the source is changed. But if you want them to be called for the first time, you could use the `immidiate: true` options. This will execute the function for the first time then execute again when the source changed.
-
- ```typescript
  watch(x, () => {
    
  }, {immidiate: true})
  ```
-
- There's also `once: true` option, which will execute the function only after the first change.
-
- There is also another watcher called `watchEffect` which is more implicit, you don't need to specify the sources, similar with `computed`, it will automatically track the sources, and it has `immidiate` option turned on by default. Look at the example:
-
- ```typescript
  // this will be used for the first time in the watchEffect
  // and normal watch with { immidiate: true }
  const todoId = ref(1) 
  const data = ref(null)
  
  // with watch
  watch(
    todoId,
    async () => {
      const response = await fetch(
        `https://jsonplaceholder.typicode.com/todos/${todoId.value}`
      )
      data.value = await response.json()
    },
    { immediate: true }
  )
  
  // the exact same thing with watchEffect, much simpler.
  watchEffect(async () => {
    const response = await fetch(
      `https://jsonplaceholder.typicode.com/todos/${todoId.value}`
    )
    data.value = await response.json()
  })
  
  ```
-
- Calling watch function usually need to have a cleanup too. You can import the `onWatcherCleanup` function from `vue` library, or you can call the callback function from the third parameter of the watcher.
-
- ```typescript
  import { onWatcherCleanup } from 'vue' // vue 3.5+ only
  
  watch(x, (newX, oldX, onCleanup) => {
    
    // you can call the third parameter
    onCleanup(() => {
      
    });
    
    // or you can call the imported function.
    // doesn't work if the watch function is async
    onWatcherCleanup(() => {
      
    });
  })
  
  // watchEffect is even simpler, it's in first parameter.
  watchEffect((onCleanup) => {
    
    onCleanup(() => {
      
    })
  })
  
  ```
-
- A watcher need to be stopped, you don't want your watcher to always run even when the component is already unmounted. Usually if you declare the `watch` directly, it will automatically stopped when the component is unmounted. Some cases don't, let's see this example.
-
- ```typescript
  <script setup>
  import { watchEffect } from 'vue'
  
  // this one will be automatically stopped by vue
  watchEffect(() => {})
  
  // ...this one will not! need to be manually stopped.
  setTimeout(() => {
    watchEffect(() => {})
  }, 100)
  </script>
  ```
-
- But it's very easy to do to. The watch function returns callback where you can call to `unwatch`.
-
- ```typescript
  const unwatch = watchEffect(() => {})
  
  // ...later, when no longer needed
  unwatch()
  ```

- ## Accessing Refs in Vue
-
- in Vue we can create a variable with a specific name, then put that name to the ref of the html element. But there's actually a better way to do that, which available in Vue 3.5+.
-
- ```typescript
  <script setup lang=ts>
  const exactName = ref<HTMLParagraphElement | null>(null);
  </script>
  
  <template>
  <p ref="exactName"></p>
  </template>
  ```
-
- The modern way:
-
- ```typescript
  // inside the function instead of direct variable name
  const whatevername = useTemplateRefs("exactName"); 
  ```
