- Today, I tried to install waydroid which is an android emulator for linux, inside a container. I'll tell you right away that you should install waydroid the normal way instead. Running waydroid requires systemd, dbus access, and more, that is when using container you need to have these access, and the only reasonable way to do that is to use rootful container. Rootful container is still a container, when you install something with your package manager like apt, dnf, yum; you still download those packages inside the container which is great, but the downsides are the engine runs as system root user, and the storage location is weirdly placed on  the `/var/lib/containers/storage` as opposed to the `~/.local/share/containers` in rootless mode, which means you have to install the image again if you previously have installed the container image in the rootless mode. And because it stored in the `/var/lib/...`, if I want to let's say reinstall my linux machine, the whole things also will get destroyed. Have you ever use flatpak? as long as I keep the `/home` directory from getting formatted, my applications will still be there after installing another linux distro. My first thought of using waydroid inside a container so that I don't need to worry my android emulator getting deleted like before when I reinstall my linux, but apparently this is the wrong way.
