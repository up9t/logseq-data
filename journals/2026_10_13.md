## Checking for a Null and Undefined value in Javascript
-
- To check a null value, you're recommended to use the `===` operator directly like this:
- ```javascript
  const a = null
  
  if (a === null) {
  
  }
  ```
- For `undefined` value though, using `typeof` is the recommended way.
- ```javascript
  const a = undefined
  
  if (typeof a === "undefined") {
  }
  ```
-
- ## Checking if a key exists in a Javascript object
-
- There are multiple ways you can use to check if a key exists in an object: `Object.hasOwnProperty`, `Object.hasOwn` and `in` keyword.
-
- `Object.hasOwn` is the modern and replcement for `Object.hasOwnProperty`, now we only got `Object.hasOwn` vs `in` keyword.
-
- ```javascript
  const a = {
    value: 1
  }
  
  // using Object.hasOwn
  if (Object.hasOwn(a, "value")) {
  }
  
  // using in keyword
  if ("value" in a) {
  }
  ```
-
- For me, and for most cases, you might want to use `Object.hasOwn` even though `in` looks cleaner. Use `in` when you want to check a key is available in an inherited object.
-
-
- ## Should I use Object or Map in Javascript?
-
- Use `Map` if you want to make a hashmap table lookup, where keys are frequently added or deleted.
- Use `{}` for plain configuration where property names are known ahead of time.
