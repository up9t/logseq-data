- In filesystem there is something called `RAID`, it is basically a way to prevent data loss by duplicating the data across multiple disks, of course you need more than one disk. RAID5 for example needs at least 3 disks and RAID10 (the combination of RAID0 + RAID1) needs at least 4, and actually RAID0 just splits the data across 2 disks and doesn't prevent any data loss if one of the disk is destroyed.
- Modern Linux Desktop including Fedora uses BTRFS filesystem by default, while Linux Server usually uses EXT4 or ZFS.
- ZFS is like BTRFS, it offers the same data loss preventation, but some comments say ZFS pushes it even further, and better than BTRFS, it also supports petabytes of storage which is great for storage server. However, it was built by the Sun Microsystem, so expect licensing stuff.
