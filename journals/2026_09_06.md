- Containerd is a runtime for managing container. It needs to be started first before able to perform any container operations.
- Docker and Kubernetes both use `containerd` as its default backend runtime.
- Podman doesn't use `containerd` as its backend runtime.
-
- ```txt
  Podman architecture:
    User → podman CLI → conmon → crun/runc → container
  
  containerd architecture:
    User → ctr/nerdctl/docker → containerd daemon → runc → container
    Kubernetes → CRI → containerd daemon → runc → container
  ```
