- In modern Android development the difference between `remember` and `rememberSaveable` is that `remember` retain data across recomposition but not across configuration change (e.g device rotation) for this you might want to use `rememberSaveable`. Important to taking note of, that both of these keywords doesn't hold data when the component got destroyed such as navigating to other page or using `if (state) ComponentA`, that will completely destroy and recreate the composition rather than just recomposition. If you need to have data that persists across navigation, you might want to store the data inside a `View Model` as it is designed to hold the data until the whole activity is destroyed.

- In Kotlin you can get the minimum or maximum number from a list using `maxOf`, `maxBy`, `minBy`, `minOf`, or `minOfOrNull`, the difference between `maxOf` and `maxBy` is that `By` returns the element that has the highest key, while `Of` returns the highest key itself like an integer or string.
